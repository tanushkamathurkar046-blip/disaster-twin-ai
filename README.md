# 🌍 DisasterTwin AI: Digital Twin for Disaster Resilience

DisasterTwin AI is a real-time AI-powered disaster risk assessment system built using Streamlit and Gemini AI.  
It helps analyze disaster scenarios like floods, earthquakes, cyclones, droughts, and heatwaves to provide risk prediction, visualization, and safety recommendations.

---

## 🚀 Features

- 📍 Location-based weather integration (OpenWeather API)
- 🤖 AI-powered disaster analysis (Google Gemini AI)
- 📊 Risk scoring system (Low / Medium / High)
- 🗺 Interactive map visualization
- 📈 Risk history tracking
- 🖼 Disaster image visualization
- 📋 Automated safety recommendations
- 📄 Downloadable AI-generated disaster report
- 🧠 Fallback emergency report system (offline mode)

---

## 🛠 Tech Stack

- Python 🐍
- Streamlit 🌐
- Pandas 📊
- Plotly 📈
- Google Gemini API 🤖
- OpenWeather API 🌦
